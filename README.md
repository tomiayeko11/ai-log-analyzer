# AI-Powered Threat Detection Log Analyzer (In Progress)

An automated security engineering pipeline built to optimize threat detection workflows using local, privacy-compliant Large Language Models.

## 🛠️ Tech Stack & Frameworks
- **OS:** macOS
- **Language:** Python 3
- **Local AI Framework:** Ollama
- **Target LLM:** Llama 3.1 (8B Parameter Model)

## 📌 Project Objectives
- **Log Parsing:** Build an automated pipeline to stream raw system and firewall authentication data.
- **Privacy-First AI Evaluation:** Leverage locally hosted open-weight LLMs to screen for brute-force attacks and credential stuffing anomalies without external cloud data exposure.
- **Automated Reporting:** Generate automated technical markdown alerts outlining structural risk indicators.
